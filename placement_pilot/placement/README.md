# 三种绕组的球面摆位试验

本试验给定绕组、峰值电流与几何摆位，计量公共靶点上的自由空间磁感应强度。球体仅提供坐标和间隙基准，球内外使用相同的真空磁导率。这里的深度是从球顶沿法线向内的几何距离。计算未包含头部组织电导率、脉冲波形和感应电场。

## 坐标与放置

名义球半径85 mm。球顶是世界坐标原点，切面是 z=0，头外方向为 +z，球心为 (0,0,-85) mm。三个轴向靶点为 (0,0,-10)、(0,0,-30)、(0,0,-50) mm，并在 z=-30 mm 取 x 或 y 方向偏移 ±10 mm 的四个对照点。七个点的三分量与场模保存在 target_fields.csv。名义激励为单位权重绕组1000 A，因此不同线圈的匝数、总安匝、导线长度和储能均可不同。

1. **八字线圈**沿用参考算例的理想化几何，每翼有半径4、12、20、28、36、44 mm的同心平面环；翼心在 x=±44 mm 处，外环相切是原先补充的建模假设。原点为相切点，y沿公切线，左右电流权重分别为−1和+1，绕制角沿 x-y 面递增。该模型与儿童八字图或商品型号有不同的几何参数。
2. **双锥线圈**直接载入已有主实验的有向线段和权重。以对称中心和双翼铰链确定 x、y 位置及方位，y沿铰链，两翼由顶端向球体两侧倾斜。95°夹角及导线参数均沿用基准几何。FOE和双锥缺少外壳网格，仅能做导线中心线碰撞检查。
3. **H1**使用原始TCD零形变坐标、18个部件及其原电流方向。配对的18组 minDistancePoints 共9920个公开标记，用其鲁棒球拟合求一个初始朝向。固定件 H1_no_def 中离模型原生原点最近的标记作为种子，取半径12 mm邻域的标记均值作为几何锚点。这是本试验明确选定的可复核点，未由临床靶点或电场定义。拟合壳体标记的球半径约100.44 mm，只用于求初始方向；实际受检的几何球半径为85 mm。
4. **H1刚体方向细调**。将锚点的切向坐标固定于球顶轴线，在初始法线30°锥内寻找使锚点离球顶尽可能近的球心，约束每条源线段离85 mm球面至少12 mm。用5个几何初值做约束局部优化，取收敛且满足约束者中锚点距离最短的一项。结果偏离初始法线25.54°。原始 +x 在切面上的投影确定方位，旋转矩阵行列式为+1。绕组形状和17项可变形连接均保持原始零角度。此几何寻优没有使用靶区场强，结果依赖所选工作锚点、角度范围和初值。
5. **统一间隙**。各模型先锁定朝向和切向位置，再从球体外沿 −z 方向靠近，求使球心到所有导线线段的最短距离等于97 mm的位置。12 mm是此最近中心线的径向净距。数字足以容纳名义刚体H1已有壳体，未由临床垫片或厂商外壳厚度指定。对每条线段求投影并将参数夹在起终点之间，同时在每条线段内再取9个点作独立上界检查。H1进一步对配套的42,476个三角形计算点到三角形面、边及顶点的最短距离，名义外壳到球面最小净距为2.247 mm。

pose.json 给出逐摆位 4×4 齐次矩阵，列向量约定为 world = R·source + t，长度均为mm。source_geometry 中保存进入矩阵的真实输入坐标，target_frame_segments 中保存名义摆位后的坐标。双锥的源坐标已包含主实验初始的z平移。pose.csv 记录锚点高度、最小净距、一个最近点的坐标及其距靶轴的横向偏移。对称绕组有多个等距点，CSV保留一个代表点。

## 敏感性和复核

除名义位姿外，每种线圈另算8个单因素工况。球半径改80/90 mm，绕组间隙改10/15 mm，沿x方向平移±5 mm，或绕世界y方向相对于源锚点整体转动±5°。每项都重新沿z求指定间隙。H1 的刚体基准方向仅在名义条件选择一次，其他工况沿用。电流始终为1000 A，无振幅扫描。由此处的线性模型，电流倍率可直接作用于B的所有分量。

名义H1的30 mm轴场为42.78 mT。间隙从12 mm调至10/15 mm时，得到44.27/36.36 mT。左右各5°整体倾斜并重新满足间隙时为26.35/34.79 mT；这一变化同时包含倾斜及为了保持净距而产生的高度变化。三个模型在9种工况中全部通过全绕组间隙检查。H1所有工况的三角外壳到球面净距均为正，其中10 mm绕组净距工况仅余0.24 mm；制造或位置误差不在该几何检查内。

另为H1增加一个工况，直接使用9920个标记给出的初始球拟合法线。两个位姿共用工作锚点、方位定义、85 mm球半径及12 mm绕组净距，都是从外侧沿z朝球体移动到指定间隙；两者总计在28个摆位、196个观察点记录中占14条记录。详细数值见 h1_orientation_comparison.csv。

| 直接采用标记拟合法线 | 0° | 105.68 | 85.11 | 2.46 | 26.76 | 20.57 | 15.57 |
| 在30°锥内使锚点靠近球顶 | 25.54° | 27.48 | 23.74 | 2.25 | 55.89 | 42.78 | 32.31 |

两个位姿都通过壳体碰撞检查。未细调的刚体在靠近过程中由远离锚点的绕组先触及间隙约束，锚点仍悬在球顶上方105.68 mm，说明该姿态难以复现靶点附近贴合。只改变方向规则，H1在30 mm处与双锥35.02 mT的大小次序即发生反转。没有实测安装位姿或独立外壳配准时，两个数值仅代表各自的指定姿态。

源坐标下的八字和双锥计算先与既有MATLAB数据逐分量核对，再对摆位后的7个观察点执行正向旋转与逆变换观察点的一致性检查。前一项误差记录于 source_field_checks.csv，两组相对L2均小于4×10⁻¹⁵。后者和逐线段采样诊断记录于 pose.csv。这些检查验证几何变换与相同线元模型的一致性。H1在真实头皮上的安装、用户特定头形和绕组连接缝隙仍影响外推。

## 复现入口

在本目录从项目Python环境运行 run_placement.py。脚本读取上级项目已有的H1、八字验证及双锥输入，重新生成源坐标、变换和结果表。为恢复原始数据输出需要 NumPy 和 SciPy。MATLAB 中切换到本目录再运行 plot_placement 可由目标坐标线元重画 nominal_registration.png。

原始H1的出处与许可见 [模型来源](../../reference_models/h1_metadata.json)、上游线圈说明〔1〕 和 Worbs 等的公开研究〔2〕。本试验的锚点、拟合方法、球尺寸与间隙属于本项目的工程定义。
