# 补充参数敏感性实验

运行：MATLAB中添加`matlab`目录后执行`run_sensitivity`。本目录所有CSV和图均来自实际MATLAB运行，I=1000 A，每匝192段，CPU双精度。

## 1. 儿童8字同名尺寸冲突

原文p.9采用4层、4圈/层、中心距70 mm；p.3–4同名图则给出中心距92±2 mm、外径90±2 mm、内径25±1 mm。较大图未明确匝数/层数，故本实验保持两者每翼每层4圈、4层、总绝对32匝以及相同1000 A电流，只改变半径和中心距离；这是等NI的受控尺寸变体，不声称重建了较大版本的真实绕组。较大变体取中心线半径14.5…43 mm、假设导线OD4 mm、层距4.5 mm，满足内孔25、外径90和总宽182<185 mm。

- z=10 mm：较大/紧凑版本 |B| 比值 0.880083。
- z=20 mm：较大/紧凑版本 |B| 比值 0.949953。
- z=30 mm：较大/紧凑版本 |B| 比值 1.057729。
- z=40 mm：较大/紧凑版本 |B| 比值 1.167738。
- z=50 mm：较大/紧凑版本 |B| 比值 1.271842。

这些比值同时受孔径、半径和中心距变化影响，不是单独半径的因果效应，也不能解释为儿童治疗效果。精确三分量和1 mm间隔深度数据见`pediatric_size_equal_NI.csv`。

## 2. 折叠角扫描

保持与主圆形模型相同的18个闭合环、半径17…55 mm、2层、层距4.5 mm和相同电流，只将x=±20 mm以外部分向远离观测区方向折0/15/30/45/60°。这组角度与20 mm铰链距离是显式实验参数，原文p.16没有给出数值。该实验只回答所选几何在空气中的B场变化，不声称存在通用最优角。

| 折角(°) | B(0,0,30mm) (mT) | z20半值面积(cm²) |
|---:|---:|---:|
| 0 | 117.717536 | 69.052500 |
| 15 | 110.051634 | 62.167500 |
| 30 | 102.818162 | 57.712500 |
| 45 | 95.832757 | 53.662500 |
| 60 | 88.951715 | 49.207500 |

半值面积定义为z=20 mm平面内 |B| ≥该平面最大值/2 的面积，正方形窗口x/y=±180 mm，主扫描81×81（4.5 mm）网格。30°加密到161×161（2.25 mm）后面积为57.054375 cm²，相对变化1.154%。边界截断标志均写入CSV；二值阈值面积存在栅格误差，不宜把微小差异视为稳定结论。该面积不是脑组织电场聚焦面积。

## 3. 长直线的中点积分误差

将每一条原有直线元等分1/2/4/8/16/32段；线元端点和直线路径不变，没有改变物理几何。对跑道形和两个示意H1，使用5个轴点(z=10…50 mm)加两个离轴点[-30,20,20]、[30,-20,50]mm比较中点积分与主程序的直线段解析积分。

- elliptical：中点相对向量L2误差 36.8183% → 0.009108%（1段→32段）。
- h1_simplified：中点相对向量L2误差 0.4759% → 0.000357%（1段→32段）。
- h1_alternative：中点相对向量L2误差 0.7900% → 0.000678%（1段→32段）。

大误差来自把长直线只在一个中点采样。主实验从始至终采用每条直线的解析积分，不存在这类长直线中点求积误差。对同一路径将解析积分细分32次，结果相对变化均<1e-10，具体值见`exact_subdivision_invariance.csv`。这里仍不消除圆弧折线逼近、源几何尺寸、引线省略或H1源重建不确定性；这些与求积误差是不同问题。
